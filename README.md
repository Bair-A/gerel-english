# Герел — репетитор английского

Одностраничный сайт-визитка репетитора английского языка Герел.

Сделан на Next.js и React, собирается в статические HTML-файлы и выкладывается на GitHub Pages: https://bair-a.github.io/gerel-english/

## Как поменять текст, цены или отзывы

Весь текст сайта лежит в одном файле — [`data/content.js`](data/content.js). Его можно отредактировать прямо на сайте GitHub (иконка карандаша). После сохранения сайт сам пересоберётся и обновится через пару минут.

Цвета и отступы — в [`app/globals.css`](app/globals.css). Акцентный цвет задаётся переменной `--accent`.

Картинки лежат в `public/assets/`.

## Структура

- `app/layout.jsx` — общий каркас страницы, шрифты, заголовок и описание для поисковиков
- `app/page.jsx` — порядок блоков на странице
- `components/` — блоки страницы (шапка, цены, отзывы и т. д.)
- `data/content.js` — весь текст
- `.github/workflows/deploy.yml` — автоматическая сборка и выкладка на GitHub Pages

## Локальный запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

Шрифты Unbounded и Manrope (лицензия SIL Open Font License) подключены через `next/font`: при сборке они скачиваются и кладутся вместе с сайтом, поэтому посетители не обращаются к серверам Google.
